# แปลนออกแบบ vs สภาพจริง — PFAL SISKU

แปลน: `data/raw/doc/Plan Layout PFAL SISKU.pdf` (Civic Agrotech, Rev. 0, tolerance ±5 ซม., 7 หน้า; ภาพหน้าละไฟล์ใน `docs/plan_drawing/page-N.png`)
**เป็นแปลนที่ใช้วางแผน ไม่ใช่ as-built** — ใช้เป็นข้อมูลอ้างอิงเทียบกับ point cloud / ภาพถ่าย และเป็นแหล่ง spec สำหรับโมเดล L3 (`data/model/design_spec.json`)

## 3. ทิศทางน้ำ (แปลนหน้า 6–7) — แก้การตีความเดิม
| แปลน | ความหมายต่อโมเดล |
|---|---|
| "**ชุดท่อน้ำเวียนขาเข้า** ชั้น Growing Stage" = ท่อยืน**ด้านประตู** มีสามทางเข้าถาด 4 ชั้น | ของจริงเป็นท่อขาว 1" + หัวท่อพร้อมวาล์วแดง 2 ตัว/ชั้น (ภาพ 2570–2573) → **ท่อจ่ายพร้อมวาล์วปรับสมดุล** |
| "**ท่อน้ำเวียนลงถัง** ชั้น Growing Stage" = ท่อยืนสีฟ้า**ปลายห้อง** ลงถัง 200 L | ท่อยืนฟ้าที่มีสามทางทุกชั้น (ภาพ 2557/2561) คือ**ท่อน้ำกลับ** ไม่ใช่ท่อจ่าย → น้ำในถาดไหล **ประตู → ปลายห้อง** |
| ปั๊มในถัง 200 L → ท่อบนพื้น → ท่อยืนขาเข้า | ท่อเมนสีฟ้า 1.5" บนพื้น = ท่อจ่ายจากปั๊มไปด้านประตู |

โครงข่ายใน `pfal_twin/hydraulics.py` / `data/model/pipe_network.json` ปรับตามนี้แล้ว (เส้นประเหลือเฉพาะภายในวงจรอนุบาล)

## 3b. เส้นทางน้ำดี/น้ำทิ้ง (pptx สไลด์ 3 "ตำแหน่งและเส้นทางท่อน้ำดีและน้ำทิ้ง" — `docs/plan_drawing/slide-3.png`)

|---|---|
| ระบบกรองน้ำ RO → ถังเก็บน้ำ RO 5 m³ → ปั๊มหอยโข่ง ≥3000 L/h → ก๊อกน้ำ RO → ท่อ RO ½" เข้าถังสารละลายทุกถัง | ✅ ทางเดินบริการข้างอาคาร: ถัง RO สลิมสีเทา, ปั๊มเหลือง, ชุดกรอง 3 ขั้น, ท่อฟ้า 2 เส้นตามผนัง → วาล์ว "น้ำ RO" / "น้ำประปา" บนผนัง X=L; ในห้องเป็นท่อขาว 2 เส้นบนพื้น |
